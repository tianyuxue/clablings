# clablings 双语一致性设计（历史记录）

> **已废弃（2026-11-18）**：本文描述的双语内容和一致性校验机制已经完全移除，仅作历史记录保留。

> 日期：2026-09-20

## 目标

当时的目标是让英文与中文内容保持技术事实一致，同时允许中文独立润色。方案包括：

1. 在 `clablings lint` 中确定性比较两种语言必须相同的结构。
2. 根据 Git 提交时间提示英文更新后中文可能过期。

语义等价当时不在自动校验范围内。

## 当时的双语范围

章节使用 `concept.en.md` 与 `concept.zh.md`；`exercise.yaml` 的人类文案使用
`localizedString`；阅读文件按 locale 命名。如今这些文件与抽象均已删除。

## 当时的校验规则

概念文档比较标题层级、围栏代码块、行内代码和链接目标；YAML 人类字段要求同时存在
`en` 与 `zh`。代码块和链接被视为语言无关技术事实。

## 当时的实现

校验逻辑位于 `internal/i18n`，内容层提供 `TranslationParity` 和
`MissingTranslations`，CLI lint 汇总错误与警告。2026-11-18 起，`internal/i18n` 已删除，
题库改为单份中文文件，本文不再指导实现。
